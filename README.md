## 📝 عن المشروع (About The Project)

**CodeQuest** هي منصة تفاعلية مخصصة للمطورين والبرمجيين لطرح الأسئلة المباشرة، تقديم الإجابات، ومشاركة الخبرات والحلول البرمجية. تم بناء المنصة باستخدام إطار العمل **Laravel** وتم دعمها بتقنيات الحاويات **Docker** لتسهيل عملية الاستضافة والنشر على منصة **Render**.

---

## ✨ المميزات الرئيسية (Key Features)

- ❓ **إدارة الأسئلة والإجابات:** إمكانية إضافة أسئلة تقنية وتفصيلية، مع توفير ردود وإجابات تفاعلية.
- 🏷️ **التصنيف والوسوم (Tags & Categories):** تنظيم المحتوى البرمجي وسهولة الوصول للحلول التقنية المطلوبة.
- 👤 **الملف الشخصي (User Profiles):** إدارة بيانات المطورين ومتابعة مشاركاتهم وإجاباتهم.
- 🐳 **دعم Docker & Cloud Hosting:** جاهزية المشروع للنشر والتطوير عبر Docker الحاويات وعلى خوادم Render.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Backend:** Laravel (PHP 8.x)
- **Frontend:** Blade Templates / Bootstrap / Vite
- **Database:** MySQL
- **Containerization & Hosting:** Docker / Laragon / Render
